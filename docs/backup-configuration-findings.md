# Backup Configuration Findings

FFM’s managed WebDev database and storage backup posture cannot be configured through application code alone. Official Manus guidance states that task data is not backed up automatically for affected accounts and that the user’s in-app notice and email determine whether backup action is required. If the account is affected or uncertain, the account owner should use the Manus Data Backup Tool and confirm the selected backup policy before any project-level backup work is planned.

Sources: [Data Backup Tool](https://manus.im/backup) and [How to Back Up Your Data](https://help.manus.im/en/articles/16147892-service-change-overview-how-to-back-up-your-data).
