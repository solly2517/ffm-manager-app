# Mobile Dashboard Return Validation

- Verified at a 390 × 844 viewport that the persistent **Dashboard** action is visible and touch-accessible in Surgery Calendar, Surgery Readiness, Travel Expenses, Work Log, and Help Center.
- The action is positioned above the mobile safe area and uses role-aware routes: Manager/Administrator to `/`, Delegate to `/delegate`, and Warehouse Hero to `/warehouse-hero`.
- Deep-workspace content receives additional mobile bottom padding so the return control does not make the final controls unreachable.
