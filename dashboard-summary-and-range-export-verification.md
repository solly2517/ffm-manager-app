# Dashboard Summary and Date-Range Export Verification

The Administrator dashboard displays the **Monthly Travel Expense summary** card before the operational statistics. It clearly explains that totals are grouped by department and currency, exposes the Travel Expenses destination, and presents an empty-state message when no claims exist in the current month.

The Finance-authorized Travel Expenses page displays an **Accounting export by date range** card with accessible `From` and `To` date inputs, inclusive-period wording, and separate Excel and CSV controls. The default range covers the first day of the current month through today.
