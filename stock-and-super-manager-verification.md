# Stock Link and Super Manager Verification

The standard FFM dashboard now shows a prominent **View stock** entry beside **Create task**. It opens the separate Stock Management application in a new tab, where the stock application's own login and permissions enforce view-only access.

The profile workspace displays the optional Department field and its explanatory text. The Super Manager roster controls, assignment relationships, and recent-report activity remain restricted to the designated Super Manager accounts and are covered by server regression tests.
